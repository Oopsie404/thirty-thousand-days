# 光阴三万 · Thirty Thousand Days

一款 macOS 桌面小组件应用。


## 为什么叫「光阴三万」

人的一生大约只有三万天。

这个数字并不是对人生长度的精确规定，而是一种提醒：时间有限，每一天都值得被看见，也值得认真度过。

「光阴三万」把抽象的时间变成可以随时查看的进度，让你看到已经走过了多少，也提醒自己还可以如何使用接下来的时间。


## 功能

- 显示今年、当月和本周的时间进度
- 支持设置出生日期和期望寿命
- 显示人生整体进度
- 统计“已来地球”和“预计再停留”的天数
- 支持自定义时间事件并查看事件进度
- 提供 macOS 桌面 WidgetKit 小组件


## 环境要求

- macOS 14 或更高版本
